> Script de la nouvelle vidéo « __NOM__ ». Une ligne par réplique : [ce qu'on voit] ce que dit la voix.
> Syntaxe complète : « refonte-youtube help script ». Les lignes qui commencent par > sont des notes.
> Exemple, à remplacer :
> # Intro
> [motion accroche] Tu perds *deux heures par jour* sans le savoir.
> [1:12-1:20 zoom=1.4@0.7,0.3] Regarde ce réglage, caché ici.
> [=] Une fois activé, tout change.
> # Le réglage caché
> [carton "3 erreurs"] Voici les trois erreurs que tout le monde fait.
